# Model Fingerprint (`modelfp`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a pure-Go, low-memory, low-merge-conflict model fingerprinting vertical slice (`internal/modelfp` + `features/model-fingerprint`) inside `ballShell/sub2api` so administrators can batch-verify claimed models across OpenAI Chat, OpenAI Responses, Anthropic Messages, and Gemini when onboarding upstream APIs, and maintain a versioned, calibrated fingerprint library.

**Architecture:** All backend logic lives inside a self-contained vertical slice `backend/internal/modelfp/` using raw `*sql.DB` idempotent schema setup (zero `ent/` or `backend/migrations/` edits), embedded `go:embed` seed suites/family maps, an SSRF-safe 4-protocol HTTP client, sequential dual-engine detection (`LogprobsDetector` -> `BehaviorProtocolDetector`) with unified prompt-injection detection, and async in-process batch jobs polled by a 4-tab Vue 3 workbench under `frontend/src/features/model-fingerprint/`. Only 5 minimal upstream touchpoints (`wire.go`/`main.go`, `handler/{handler,wire}.go`, `routes/admin.go`, `middleware/audit_log.go`, and frontend router/sidebar/i18n) connect the module to Sub2API.

**Tech Stack:** Go `1.27.4`, Gin, Google Wire DI, PostgreSQL 16 (`database/sql`), Vue 3, TypeScript, Tailwind CSS, Vitest, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-25-modelfp-design.md`

## Global Constraints

- Go version must remain `1.27.4` (`backend/go.mod`); code must pass `go test -tags=unit ./...` and `golangci-lint run ./...` (v2.13) with zero new issues.
- Frontend must use `pnpm` (do not add heavy third-party dependencies; if `package.json` changes, sync `pnpm-lock.yaml`) and pass `pnpm run check:i18n`, `pnpm run typecheck`, `pnpm run test:run`, and `pnpm run build`. (On hosts without native `go 1.27.4` or `pnpm`, run the exact commands inside `golang:1.27.4` / `node:22` containers.)
- Runtime footprint: pure Go in-process, zero extra Docker containers, < 15 MB resident memory overhead; per-response read cap `256 KB`; probe timeouts `30s` (`60s` for `openai_responses`); batch run cap `50` models; concurrency `1..5` (default `3`); capture rounds `K` in `3..5` (default `3`).
- Naming isolation: package `modelfp`, DB table prefix `modelfp_`, Admin HTTP prefix `/api/v1/admin/model-fingerprint`, frontend route `/admin/model-fingerprint`. Never reuse `fingerprint` / `tlsfingerprint` / `anthropicfp`.
- Strict upstream isolation: do NOT modify `ent/schema/*.go`, `backend/migrations/*.sql`, `account_test_service.go`, `channel_monitor_*.go`, or `ModelWhitelistSelector.vue`.
- Account scope: `source = "account"` supports ONLY standard REST API Key accounts (`AccountTypeAPIKey` / `AccountTypeUpstream`, `ParentAccountID == nil`) on `openai`, `anthropic`, `gemini`, `kimi`, `zhipu`, `deepseek`, `minimax`; reject OAuth/`setup-token`/shadow/Bedrock/Vertex/Antigravity with `400 MODELFP_UNSUPPORTED_ACCOUNT_TYPE`. Apply `model_mapping` and `header_overrides` and record both `claimed_model` and `upstream_model`.
- Security & secrecy: ad-hoc targets accept only pre-configured `proxy_id` (no free-text `proxy_url`); enforce SSRF URL + socket `DialContext` checks; never persist/log/echo temporary API keys, `extra_headers`, or private canary prompts; omit request bodies in `audit_log.go` for all 5 credential/canary write routes.
- Dual-engine semantics: capture runs BOTH `logprobs` and `behavior` probes on `openai_chat`/`gemini` (persisting 2 rows when `logprobs` succeeds, 1 `behavior` row otherwise); verification uses strict sequential fallback (`logprobs` -> `behavior`) with unified `prompt_injection_suspected` checks (`expected_max_prompt_tokens`, default `500`).

## Review Focus

1. **Base URL path variations (`/v1`, trailing slashes, custom prefixes like `/openai/v1`)**: normalizing base URLs must never produce `/v1/v1/chat/completions` or strip a custom path prefix (`Task 2`: `TestNormalizeProtocolEndpoint`).
2. **Secret & private-canary non-leakage**: transport error strings must never leak API keys, default bundle export (`include_private=false`) must strip private suites and their baselines, and `audit_log.go` must omit bodies on all 5 write routes (`Task 2`: `TestTransportErrorRedactsAPIKey`, `Task 6`: `TestExportBundleExcludesPrivateByDefault`, `Task 8`: `TestAuditLogOmitsModelFPBodies`).
3. **Stripped `logprobs` (HTTP 400 or `null`) combined with 4K system-prompt injection**: upstream rejecting `logprobs` must transparently retry without `logprobs`, fall back to `BehaviorProtocolDetector`, and still flag `prompt_injection_suspected = true` with `observed_prompt_tokens` (`Task 2`: `TestOpenAIChatRetriesWithoutLogprobsOn400`, `Task 3`: `TestOrchestratorFallbackPreservesInjectionWarning`).
4. **Zero-variance or empty-library baseline calibration**: $D_{\text{self}} = 0$ or missing nearest neighbor ($D_{\text{near}}$ absent) must clamp thresholds into spec safety bounds (`[0.03, 0.25]` for `logprobs`, `[0.12, 0.38]` for `behavior`) instead of collapsing to `0.0` (`Task 1`: `TestDeriveThresholdsEdgeCases`).
5. **Mid-batch cancellation, server restart recovery, and malformed model lists**: cancelling stops pending probes and sets run status `cancelled`; `Start()` marks leftover `queued`/`running` runs & capture jobs `failed: server restarted`; duplicate/blank model names are normalized before enforcing the 50-model cap (`Task 4`: `TestMarkStaleRunningJobsFailed`, `Task 7`: `TestVerifyServiceCancelAndModelNormalization`).
